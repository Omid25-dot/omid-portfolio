# Personal portfolio versions

These are standalone versions of omidmerati.com, separate from the Next.js rental application.

- `blue-violet-scroll-2026-11-02/index.html`: exact saved copy of the blue/violet gradient design before the glyph-rain experiment. Self-contained, with the existing Google Fonts links. To restore this design, copy it to the repository's root `index.html`.
- `terminal-rain-preview/index.html` and `glyph-rain.js`: an experimental original falling-glyph background, using the saved portfolio's content, theme, cursor and scroll interactions. This is independently authored JavaScript, not the licensed React Bits Pro Terminal Rain component. Open through a local server to review it.
- `particle-text-preview/`: the user's supplied React Bits `ParticleText` source integrated into a separate portfolio preview. Two instances render “Omid” and “Merati” using the existing Syne font and blue/lavender accents. Includes the preceding original glyph rain and scroll effects. The component adds `paused` and `onReady` props for the portfolio motion control/text fallback, and left-aligns sampled text. Source: the pasted component supplied in chat on 2 November 2026. Build the checked-in browser assets with `node portfolio-versions/particle-text-preview/build.mjs` from the repository root; the build uses the existing installed React, React DOM and esbuild packages without changing the rental application's dependencies. Serve this directory's `index.html` and its adjacent generated assets together.

- `electric-terminal-preview/`: saved blue/violet portfolio with the supplied React Bits `ElectricBorder` component wrapped around the existing terminal node. Includes the original name typography, custom cursor and gradient background; no ParticleText or glyph rain. Its source lives here; rebuilding with `node portfolio-versions/electric-terminal-preview/build.mjs` also refreshes the static assets under `portfolio-assets/electric-border/` used by the current root homepage.

- `live-original-2026-11-02/index.html`: exact downloaded copy of the public omidmerati.com page, with its cream/black/lime design and original content. Restore this file to root `index.html` to remove all experimental additions.
- `live-electric-terminal/`: the downloaded live design with the user-supplied ElectricBorder around the existing terminal. Its build script updates `portfolio-assets/electric-border/` for the current root page. This version adds a small terminal-local play/pause control and follows reduced-motion preferences. It does not include the blue/violet redesign, glyph rain or ParticleText.

- `live-electric-before-gradient/index.html`: saved root homepage before the interactive background addition. Restore it to the repository root to retain the live design plus ElectricBorder without the animated gradient.

The current root `index.html` now uses the live design's typography/content, ElectricBorder around the terminal, and an original interactive pastel mesh background with floating decorative code/geometry. Background assets are in `portfolio-assets/ambient-gradient/`; they require no build step. Pointer movement changes their parallax, clicks create colour ripples, and the background starts automatically with no play/pause control, as requested. The original live snapshot and previous experiments remain saved. No licence key or registry download was used: the React component sources were supplied by the user in chat. Nothing has been pushed or deployed.
